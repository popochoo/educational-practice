# Модуль 3: Интеграция формы с БД (CRUD-операции и обновление UI)

Модуль отвечает за полную интеграцию графического интерфейса с СУБД PostgreSQL. Обеспечена поддержка двух режимов работы карточки и сохранение ссылочной целостности данных.

## ⚙️ Что реализовано

- **Режим добавления (INSERT)**: Отправка данных новой организации в PostgreSQL с автоматическим триггерным обновлением списка на главной форме без перезапуска.
- **Режим редактирования (UPDATE)**: Передача `partner_id` по клику на карточку, автоматический запрос `SELECT` для наполнения полей актуальными данными и сохранение изменений через `UPDATE`.
- **Безопасность**: Запросы вынесены в конфигурационный файл `.env`, считываемый встроенным парсером.

## 🚀 Как запустить

1. Настройте доступы в файле `.env`.
2. Выполните в терминале из директории этого модуля:

```bash
python main.py
```
