# Модуль 4: Обработка исключений, тестирование и аудит безопасности

Финальная, максимально отказоустойчивая сборка приложения. Система защищена от некорректного ввода пользователя и внешних сбоев СУБД, покрыта модульными тестами и прошла аудит безопасности.

## ⚙️ Что реализовано

- **Комплексная валидация**: Проверка обязательности полей и валидация рейтинга (целое неотрицательное число).
- **Интерактивные UX-окна**: Диалоги `Error` (ошибки ввода), `Warning` (предупреждение о потере данных при отмене) и `Information` (успешное сохранение).
- **Аудит безопасности**: 100% защита от SQL-инъекций благодаря параметризации аргументов (`%s`) во всех запросах к PostgreSQL.
- **Логирование**: Запись непредвиденных исключений в отчетный файл `app.log` с указанием даты и времени.
- **Калькулятор сырья**: Интеграция метода расчета материалов с обработкой граничного значения `-1`.

## 🚀 Как запустить и протестировать

### 1. Запуск CRM-приложения:

```bash
python main.py
```

### 2. Запуск модульных Unit-тестов (5 тест-кейсов математического ядра):

```bash
python test.py
```
