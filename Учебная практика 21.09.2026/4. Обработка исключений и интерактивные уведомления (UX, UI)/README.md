# Учебная практика — ИС «CRM Реестр партнеров»

Данный репозиторий содержит пошаговое выполнение практических заданий по разработке десктопного интерфейса CRM-системы, интеграции с СУБД PostgreSQL, реализации CRUD-операций и обработке исключений.

## 📁 Структура каталогов

Каждая папка соответствует отдельному этапу выполнения лабораторной работы:

- `1. Проектирование многооконной архитектуры` — базовая навигация между окнами.
- `2. Разработка формы добавления, редактирования партнера` — верстка полей формы и плейсхолдеры.
- `3. Интеграция формы с БД` — реализация SQL-запросов INSERT и UPDATE.
- `4. Обработка исключений и интерактивные уведомления` — комплексная валидация данных и диалоговые UX-окна (Финальная версия).

Каждый этап содержит свой изолированный файл конфигурации `.env` и исполняемый скрипт `main.py`.

---

## 🚀 Как запустить приложение

Для запуска финальной версии (или любого отдельного этапа) выполните следующие шаги:

### 1. Настройка конфигурации базы данных

Внутри выбранной папки откройте файл `.env` и укажите актуальные параметры подключения к вашей локальной СУБД PostgreSQL:

```env
DB_NAME=имя_вашей_базы
DB_USER=postgres
DB_PASSWORD=ваш_пароль
DB_HOST=localhost
DB_PORT=5432
```

### 2. Установка зависимостей

Для взаимодействия Python с PostgreSQL требуется установить официальный native-драйвер. Откройте терминал и выполните команду:

```bash
python -m pip install psycopg2-binary
```

### 3. Запуск скрипта

Перейдите в терминал и запустите главный файл:

```bash
python main.py
```
