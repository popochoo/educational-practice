# Автоматизированное тестирование, аудит безопасности и UX

Финальный модуль учебной практики по интеграции многооконного интерфейса CRM, реализации ETL-очистки данных в 3NF, комплексной валидации полей и покрытию бэкенда юнит-тестами.

## 📁 Описание файлов модуля

- `main.py` — главное десктопное приложение (интерфейс Tkinter, интеграция с БД, валидация и калькулятор сырья).
- `test.py` — модуль автоматизированного тестирования (5 тест-кейсов на фреймворке `unittest` с мокированием контекста СУБД).
- `schema.sql` — DDL-скрипт создания структуры БД в 3NF и ETL-миграции сырых данных со скрытыми аномалиями.
- `.env` — конфигурационный файл подключения к вашей локальной базе данных PostgreSQL.
- `app.log` — отчетный лог-файл для автоматической фиксации системных исключений времени выполнения.

---

## 🛠 Инструкция по запуску проекта для преподавателя

### 1. Подготовка и наполнение базы данных

Запустите сервер PostgreSQL и выполните скрипт инициализации структуры и ETL-очистки данных `schema.sql`:

```bash
psql -U postgres -d practice_db -f schema.sql
```

_Результат_: Будут созданы таблицы `partners`, `products`, `sales_history` в 3NF, очищены пробелы (`TRIM`), нормализованы разноформатные даты к стандарту `YYYY-MM-DD`, а битая запись с `id = 999` будет отфильтрована.

### 2. Настройка файла окружения

Создайте в папке файл `.env` и укажите параметры вашей локальной СУБД:

```env
DB_NAME=practice_db
DB_USER=postgres
DB_PASSWORD=ваш_пароль
DB_HOST=localhost
DB_PORT=5432
```

### 3. Установка зависимостей

Установите драйвер подключения Python к PostgreSQL:

```bash
python -m pip install psycopg2-binary
```

### 4. Запуск CRM-приложения

Запустите главный исполняемый файл:

```bash
python main.py
```

_Навигация в UI_:

- **Одиночный клик** на карточку партнера — визуальное выделение и активация кнопки «История продаж».
- **Двойной клик** на карточку партнера — открытие режима редактирования (UPDATE) с автозаполнением полей.

### 5. Запуск автоматизированных Unit-тестов

Для проверки отказоустойчивости математического ядра (расчет материалов с округлением строго вверх, обработка отрицательных параметров и несуществующих ID с возвратом `-1`) запустите тестовый модуль:

```bash
python test.py
```
